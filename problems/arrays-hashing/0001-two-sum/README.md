# 1. two-sum (Easy)

- 問題: https://leetcode.com/problems/two-sum/
- NeetCode: https://neetcode.io/problems/two-sum
- カテゴリ: arrays-hashing

## 解法を一言で
素直に解決しようとすると、2重ループを組んで相方を片っ端から探しにいくことになる。

そこで、ペアはtarget - 自身(num)を引いた値であるため、検証値にペアがいるかどうか、という存在チェックである、という発想に切り替える。

mapを使い、ペアのvalueとvalueがいたindexを保持しておけば良い。

## 計算量

- 時間: O(n)
- 空間: O(n)

## 詰まった点・覚えること
### スライスへの値の追加方法
スライスに値を追加したいときは、スライス = append(スライス, 追加要素)で記入する
``` go
result := []int{}
i := 3

result = append(result, i)
```

Goのスライスの正体は、次の3つをまとめた小さな構造体
```
スライス = { 配列へのポインタ, len（長さ）, cap（容量） }
```
関数に渡すと、この構造体がコピーされるため、appendの中でlenを増やしても、呼び出し元のlenは変わらない。
そのため、appendは「更新後のスライス」を戻り値で返し、こちらで受け取り直す構造となる。

つまり、受け取り直さないとlenが書き変わらないため、ポインタの先を何個目までみていいかが更新されないことになる。

### mapの存在チェック
``` go
v, ok := m[key]
if ok {
    // key が存在する
}
```
ifの中にまとめて書くのが定番
``` go
if v, ok := m[key]; ok {
    // 存在するときの処理
}
```

なぜokが必要なのか？
→Goのmapは、存在しないキーを引いてもエラーにならず、型のゼロ値を返すから。
``` go
m := map[int]int{5: 0}

m[5]  // 0（キー5は存在して、値が0）
m[9]  // 0（キー9は存在しない → int のゼロ値）
``` 
値だけでは、「本当に0が入っている」のか、「存在しない」のか区別ができないから。

### mapへの追加方法
m[key] = valueと代入する
``` go
m := map[string]int{}
m["apple"] = 3   // 追加（キーがすでにあれば上書き）
m["apple"]++     // 値を更新
```
