# 347. top-k-frequent-elements (Medium)

- 問題: https://leetcode.com/problems/top-k-frequent-elements/
- NeetCode: https://neetcode.io/problems/top-k-frequent-elements
- カテゴリ: arrays-hashing

## 解法を一言で
その値が取りうる範囲が
1. 整数
2. 最小値と最大値が前もってわかる
3. その幅が十分小さい
場合、バケットソートを使用して、大きい順に出現した値をk個スライスに入れて返却する

## 計算量

- 時間: O(n)
- 空間: O(n)

## 詰まった点・覚えること
### ゼロ値と初期値、スライスとmapの作り方の違い
スライス→(型, 長さ, 容量)

map→(型, 容量のヒント)
``` go
var s []int // (nil, len 0, appendできる)。箱はあるけど中身がどこのポインタも差していない。
make([]t, n) // ゼロ値がn個。 箱はあり、n個分のスライスにアクセスできる状態。
make([]t, 0, n) // 空(append用)。箱はあるものの、1つもアクセスできない状態。
make(map[K]V, n) // 空(lenは0)
```
スライス
第二引数nのケース→[0, 0, ...n]のスライスが作成される。インデックスでアクセスしたい時に使う

第二引数0のケース→[0, 0, ...len(cap)]分のスライス容量が確保される。実際に出来上がるのは[]という空のスライス。アクセス可能なのはappendした分だけ。

### makeと{}の使い分け
mapに関しては、makeも{}も一緒。
ただ、makeは容量のヒントが出せること、{}は初期値を入れられる、という違いがある。
